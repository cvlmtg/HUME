  H U M E   T U T O R
===================================================================
  A hands-on introduction to HUME — Hume's Unfinished Modal Editor.
===================================================================

Welcome. This buffer is your practice space. Every lesson has
exercises with text you are meant to edit. Do so freely — you cannot
break anything here. To reset this buffer to its original state,
close it with `:bd!` and re-open it with `:tutor`.

When you are ready, move to the Introduction below. Press `j` to
move down.

To quit at any time, type `:q` and press Enter.

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
  I N T R O D U C T I O N
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

HUME is a modal editor. You spend most of your time in Normal mode,
where keys perform commands rather than typing text. Press `i` to enter
Insert mode and type; `Esc` to return to Normal mode.

The most important thing about HUME: the cursor IS the selection.
The selection always covers at least one character — the one "under"
the cursor.

This shapes HUME's editing model: SELECT FIRST, ACT SECOND. Make a
selection (navigate to a word, extend to a region, match a pattern),
then apply a command (delete, change, yank). Build the selection, then
act. Every lesson builds on this idea.

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
  L E S S O N   1 — M O V I N G   A R O U N D
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1.1  BASIC MOTION

  h   move left       l   move right
  j   move down       k   move up

The arrow keys also work, but `h j k l` keep your hands on the home
row. Try them now on the practice text below.

  >> Navigate to every word in this sentence and read it carefully.

1.2  WORD MOTION

  w   select the next word (stops at punctuation boundaries)
  W   select the next WORD (whitespace-delimited; ignores punctuation)
  b   select the previous word
  B   select the previous WORD

The difference: in `config.toml log-file`, pressing `w` repeatedly
selects `config`, then `.`, then `toml`, then `log`, then `-`, then
`file` (six steps — dots and dashes are boundaries). Pressing `W`
instead selects `config.toml`, then `log-file` (two steps — only
whitespace divides WORDs).

  >> Try `w` on the line below and watch it step through each piece.
     Then navigate back to the start of the line with `b` and try `W`,
     then navigate back once more with `B`.

  config.toml log-file backup.zip

1.3  LINE MOTION

  0   or  Home    go to start of line (first character)
  ^               go to first non-blank character
  $   or  End     go to end of line (last character)

  >> Navigate to the start and end of this intentionally long line:

  Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed eiusmod.

1.4  THE JUMP LIST

  Ctrl+o   jump backward through your movement history
  Ctrl+i   jump forward through your movement history

Opening a file, jumping to search results, or switching buffers all
record an entry. Use `Ctrl+o` to retrace your steps — for instance,
to return from a tutor exercise to wherever you were before.

Some Ctrl key combinations — including `Ctrl+i` — require the Kitty
keyboard protocol to work correctly. Without it, the terminal cannot
distinguish `Ctrl+i` from Tab, so the forward-jump command will not
fire. To check whether the protocol is active, look for the cat
glyph (ᓚᘏᗢ) in the statusline.

1.5  JUMPING AROUND

  gg  go to the FIRST line of the buffer
  ge  go to the LAST line of the buffer

  {   jump to the previous blank line (paragraph start)
  }   jump to the next blank line (paragraph end)

  >> Press `ge` now to jump to the end of the tutor, then `gg` to
     return to the top, then press `Ctrl+o` twice to return here.

1.6  COUNT PREFIXES

  Prefix a motion with digits to repeat it:

    3w   step three words forward
    5j   move five lines down
    2{   jump two paragraphs back

Counts apply to motions, not edits.

Note: `0` alone jumps to line start; with a count already pending,
it becomes a digit (so `10w`, `20j`).

  >> Place the cursor on `one` in the line below, then press `3w` to
     jump three words forward. You should land on `four`:

one two three four five six

  >> Now press `2b` to jump two words backward. You should land back
     on `two`.

  ── Lesson 1 Summary ─────────────────────────────────────────────
  h j k l    basic motion         gg / ge      first / last line
  w / W      next word / WORD     0 ^ $        line start / end
  b / B      prev word / WORD     { }          paragraph motion
  3w / 5j    count + motion       3f. / 3n     count + find / search
  Ctrl+o / Ctrl+i   jump backward / forward in movement history
  ─────────────────────────────────────────────────────────────────

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
  L E S S O N   2 — E D I T I N G   W I T H   S E L E C T I O N S
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Every action in HUME consumes the current selection. The single
character under your cursor is always selected — you can act on it
immediately without making an additional selection first.

2.1  DELETE

  d   delete the current selection

With a fresh 1-char selection, pressing `d` deletes the character
under the cursor.

  >> Delete every `X` in the line below using `d`:

  The Xquick Xbrown Xfox

  >> Now press `w` to select the word "REMOVE", then `d` to delete it:

  Please REMOVE this word from the sentence.

  >> To delete a WHOLE LINE: press `x` (line-select) then `d`.
     Delete the line labelled DELETE-ME:

  Keep this line.
  DELETE-ME
  Keep this line too.

2.2  CHANGE

  c   delete the selection and enter Insert mode

  >> Select the word "wrong" with `w`, then press `c` and type "right",
     then press `Esc`:

  This word is wrong.

2.3  REPLACE

  r<char>   replace every character in the selection with <char>

Unlike `c`, replace stays in Normal mode — no Insert, no Esc needed.
On a 1-char selection it swaps the single character under the cursor.
On a wider selection it overwrites every character in the range
(newlines are preserved to keep line structure intact).

  >> Navigate onto the `X` below and press `r!` to swap it:

  Hello X World

  >> Press `w` to select the word "aaaaa", then press `r-` to replace
     every character with a dash:

  remove aaaaa this

2.4  UNDO AND REDO

  u   undo    U   redo    (Ctrl+r also redos)

  >> Press `o` to open a new line below this one, type `hello world`,
     then press `Esc`. Press `u` to undo the entire insert — the new
     line disappears. Press `U` to redo it.

  ── Lesson 2 Summary ─────────────────────────────────────────────
  d   delete selection      c   change selection
  r<char>  replace each selected char (stays in Normal mode)
  u   undo                  U   redo
  Select first, then act — the selection is always ready.
  ─────────────────────────────────────────────────────────────────

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
  L E S S O N   3 — Y A N K ,   P A S T E ,
                    A N D   T H E   K I L L   R I N G
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

HUME has two stores for copied text: the CLIPBOARD (shared with the
system) and the KILL RING (internal to the editor).

  y   yank (copy) the selection to the clipboard and kill ring
  p   smart-paste after the selection
  P   smart-paste before the selection

3.1  YANK AND PASTE

`y` copies the selection but leaves it selected. Because `p` pastes
OVER a multi-character selection (replacing it), pressing `p` right
after `y` silently overwrites the selection with an identical copy —
it looks like nothing happened.

To paste a separate copy, collapse the selection to a single character
first with `;`, then press `p`. After the first paste, each further
`p` stacks another copy adjacent to it.

`d` and `c` remove their text, so the selection is already collapsed
when you paste — only after `y` do you need the explicit `;`.

  >> Yank the word "fruit" with `w y`. Press `;` to collapse the
     selection, then `p` to paste a copy after it. Press `p` again
     to add a second copy:

  I like fruit very much.

  >> Select the line "COPY ME" with `x`, yank with `y`. Press `;` to
     collapse the selection, then `p` to paste the line below:

  COPY ME

When the cursor covers a single character, `p` inserts after it.
When the yanked text was a whole line (selected with `x`), `p` inserts
a new line below.

3.2  THE KILL RING

`c` and `d` (change and delete) push their result into the kill ring
separately from the clipboard. The ring keeps the 10 most recent
kills; the oldest drops off when an eleventh arrives.

  [   cycle to the older kill-ring entry and paste it
  ]   cycle to the newer kill-ring entry and paste it

`[` and `]` only work right after a paste — while the paste is still
"live". Pressed otherwise they do nothing. The whole paste-and-cycle
sequence collapses into one undo step: a single `u` reverts all of it.

  >> Delete the word "OLD" below with `w d`, then delete "ALSO" with
     `w d`. Now press `p` — smart-paste gives you the last kill. Press
     `[` to cycle to the older kill-ring entry:

  OLD word and ALSO word here.

3.3  SMART PASTE

`p` is context-aware:
  - after `c` or `d` (a kill), it reads from the kill ring
  - otherwise it reads from the clipboard

This means you can delete something with `d` and immediately `p`
to paste the deleted text, without switching registers manually.

If the clipboard is empty when `p` would read it, it falls back to
the most recent kill so there is always something to paste.

  ── Lesson 3 Summary ─────────────────────────────────────────────
  y         yank to clipboard + kill ring   p / P  paste after / before
  c / d     push to kill ring (10)          [ / ]  cycle ring (after paste)
  p reads from kill ring after c/d, from clipboard otherwise
  y leaves the selection — press `;` to collapse before pasting a copy
  ─────────────────────────────────────────────────────────────────

  L E S S O N   4 — I N S E R T I N G   T E X T
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

To type text you must enter Insert mode. There are several ways to
start inserting, each placing the cursor at a slightly different spot.

  i   insert at the START of the current selection
  a   insert at the END of the current selection
  I   insert at the beginning of the line (first non-blank)
  A   insert at the end of the line
  o   open a new line BELOW the cursor and enter Insert
  O   open a new line ABOVE the cursor and enter Insert

  Esc   or   Ctrl+c   exits Insert mode.

4.1  BASIC INSERT

  >> Navigate to the blank after "Name:" and press `a` to append.
     Type your name, then press `Esc`:

  Name:

  >> Use `I` to prepend "DONE: " to the line below (press `I`, type
     the prefix, then `Esc`):

  finish this task

4.2  OPEN NEW LINES

  >> Press `o` on the line below, then type `Shopping list item 2`.
     Press `Esc` when done:

  Shopping list item 1:

  >> Press `O` on the line below, then type `Shopping list:` as a
     title. Press `Esc` when done:

  First item of the list.

4.3  REPLACE A WORD

The canonical "change a word" workflow:
  1.  w   (select the whole next word)
  2.  c   (delete it and enter Insert)
  3. type the replacement
  4.  Esc

  >> Navigate onto the word "placeholder", press `w` to select it,
     press `c`, type `42`, press `Esc`. The line should read:
     The value is 42.

  The value is placeholder.

  ── Lesson 4 Summary ─────────────────────────────────────────────
  i / a    insert at start / end of selection
  I / A    insert at line start / end
  o / O    open new line below / above
  Esc      return to Normal mode
  ─────────────────────────────────────────────────────────────────

  L E S S O N   5 — F I N D ,   T I L L ,   A N D   R E P E A T
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

5.1  FIND

  f<char>   move the selection onto the next occurrence of <char>
  F<char>   move backward onto the previous <char>
  t<char>   move to just BEFORE the next <char>
  T<char>   move to just AFTER the previous <char>

These are single-key commands followed by one character. The selection
lands on (or just before/after) the target — a fresh 1-char selection.
To select a range up to a char, use Extend mode (see Lesson 7.4).

  >> Press `f.` (find dot) to jump the selection onto the period in
     this sentence. The selection shrinks to just the period.

  Navigation example. Land on a period.

  >> Press `t,` (till comma) to land just before the comma below:

  original text, keep the rest.

5.2  REPEATING FIND

  =   repeat the last find/till in the same direction
  -   repeat the last find/till in the opposite direction

  >> Press `f-` to find the first dash below, then `=` repeatedly to
     advance through each one:

  one - two - three - four - five

5.3  REPEATING THE LAST ACTION

  .   repeats the last edit action (delete, change, insert sequence)

Important: the dot command repeats the ACTION only — not the preceding
motion. After `.` you are on whatever the current selection is.

The idiomatic pattern for repeating an edit across several words:
  w   (select next word)
  c   (change it, type replacement)
  Esc
  w   (select next word)
  .   (repeat the change on the new selection)
  w
  .   ...and so on.

  >> Change the first "OLD" to "NEW" below, then use `w .` (or `w .`
     again) to change the remaining occurrences:

  OLD word and OLD word and OLD word.

  ── Lesson 5 Summary ─────────────────────────────────────────────
  f<c> / F<c>   find char forward / backward (inclusive)
  t<c> / T<c>   till char forward / backward (exclusive)
  = / -         repeat find in same / opposite direction
  .             repeat last action (not motion — re-select manually)
  ─────────────────────────────────────────────────────────────────

  L E S S O N   6 — S E A R C H   A N D   T E X T   O B J E C T S
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

6.1  SEARCH

  /   search forward (opens a prompt; type pattern, press Enter)
  ?   search backward
  n   jump to the next match
  N   jump to the previous match
  *   use the CURRENT SELECTION as the search pattern

The selection lands on the match. Press `n` to advance.

  >> Search for "needle" below using `/needle` Enter:

  There is a needle in this haystack needle and another needle here.

To clear the search highlights, press `Esc`. The highlights
disappear, but the pattern is remembered — pressing `n` or `N`
brings it back.

  >> Navigate onto the word `apple` below and press `*` to use it as
     the search pattern. Press `n` to jump to the next `apple`, then
     `n` again for the third one:

I had an apple for breakfast, an apple for lunch, and a third apple
for dinner.

6.2  TEXT OBJECTS

Text objects select structured regions. Prefix `mi` for INNER (without
delimiters) or `ma` for AROUND (including delimiters):

  mi(  mi)    inner parentheses     ma(  ma)  around parentheses
  mi[  mi]    inner brackets        ma[  ma]  around brackets
  mi{  mi}    inner braces          ma{  ma}  around braces
  mi"         inner double-quoted   ma"       around double-quoted
  mi'         inner single-quoted   ma'       around single-quoted
  mi`         inner backtick        ma`       around backtick
  mil         inner line            mal       around line (incl. \n)
  mia  maa    inner / around argument (comma-separated)
  miw  maw    inner / around word

  >> Delete the content inside the parentheses below using `mi( d`:

  The result is (REMOVE THIS CONTENT) and nothing else.

  >> Select around the string literal (including quotes) using `ma"`,
     then yank with `y`:

  The message is "hello, world" and should be kept.

6.3  SURROUNDING DELIMITERS

  ms<char>   select the TWO surrounding delimiter characters as cursors

This selects both the opening AND closing delimiter, giving you two
independent cursors. You can then delete both with `d`, or change them
with `r` + a new delimiter character.

Note: if you have the `core:helix-surround` plugin loaded, the `ms`
binding has different semantics — consult that plugin's docs.

  >> Navigate into the parentheses below and press `ms(` to select both
     delimiters, then `d` to delete them (the parens, not the content):

  This (surrounded text) needs its parentheses removed.

  ── Lesson 6 Summary ─────────────────────────────────────────────
  / ? n N    search forward / backward / next / prev
  *          use selection as search pattern
  mi<d> / ma<d>  inner / around text object
  ms<d>      select surrounding delimiter pair
  ─────────────────────────────────────────────────────────────────

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
  L E S S O N   7 — M U L T I - S E L E C T I O N
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

HUME can hold many independent cursors simultaneously. This lesson
covers how to create and manage them.

7.1  SELECT ALL

  %   select the entire buffer as a single selection

This is the starting point for many multi-cursor workflows: select
everything, then narrow it down with a pattern.

  >> Press `%` and observe the selection covers every character. Then
     press `;` to collapse back to a single-character selection. Press
     Ctrl-o to jump back to where you were before `%`.

7.2  SPLIT BY PATTERN

  s   split the current selection(s) by a regex pattern

Each match within the selection becomes its own cursor. Works on any
selection, not just the whole buffer.

  >> Press `%` to select all, then `s` and type "MARK" and press Enter
     to put a cursor on every occurrence:

  First MARK here and second MARK there and a final MARK at the end.

The canonical multi-cursor entry: `%` (select all) → `s<pattern>`
(collect matches) → edit (applies to all cursors simultaneously).

7.3  LINE SELECTION

  x   select the current line (including the newline)
  X   select the line in the backward direction
  Ctrl+x   like  x , but EXTENDS (accumulates) rather than replaces

Repeated `x` walks selection down through multiple lines.

  >> Navigate onto the first line of the exercise, press `x` to select
     it, then press `Ctrl+x` twice to extend to all three lines.
     Then press `d` to delete all three at once:

  Line alpha — select and delete me.
  Line beta  — select and delete me.
  Line gamma — select and delete me.

7.4  EXTEND MODE

  e   toggle Extend mode (statusline shows  EXT )

In Extend mode, every motion ADDS to the selection rather than
replacing it. Press `e` again to leave Extend mode. Check the
bottom-right corner of the window — it shows the current mode
( EXT  when active,  NOR  when not).

  >> Press `e` to enter Extend mode, then press `w` several times to
     grow the selection across multiple words. Press `d` to delete the
     entire extended selection, then `e` again to leave Extend mode:

  Extend: remove all of these words right here.

ONE-SHOT EXTEND WITH CTRL

You can extend the selection for a single motion without entering
Extend mode by holding Ctrl. Every motion supports it:

  Ctrl+w     extend to the next word (parallel to `e` then `w`)
  Ctrl+f<c>  extend forward to <char> (inclusive)
  Ctrl+t<c>  extend forward to just before <char>
  Ctrl+F<c>  extend backward to <char>
  Ctrl+T<c>  extend backward to just after <char>

The idiomatic delete-to-char pattern:
  Ctrl+f.   (extend the selection to the next period)
  d         (delete the entire span)

NOTE: one-shot Ctrl extend requires the kitty keyboard protocol
(look for the cat glyph ᓚᘏᗢ in the statusline). Without it,
Ctrl+w / Ctrl+f / Ctrl+t do nothing — use Extend mode instead.

  >> (Kitty) Press `Ctrl+w` a few times to grow the selection across
     words below, then `d` to delete the span.
  >> (Legacy) Press `e` then `w` repeatedly to the same effect.

  grow this selection word by word then delete it

  >> (Kitty) Press `Ctrl+f,` to extend the selection to the comma
     below, then `d` to delete the selected span.
  >> (Legacy) Press `e` then `f,` to the same effect.

  Select everything up to this comma, then delete it.

7.5  COLLAPSING AND PRUNING SELECTIONS

  ;      collapse the selection to a single-character selection at HEAD
  ,      keep only the PRIMARY selection (discard all others)
  Ctrl+; collapse the selection to a single-character selection at ANCHOR
  Ctrl+, remove the PRIMARY selection, keeping all others

Note: `Ctrl+;` and `Ctrl+,` require the kitty keyboard protocol.

After a multi-cursor operation (e.g. `%` then `s`), you may have
many cursors. Use `,` to get back to just one.

  >> Select the line below with `x` then `s` and type "TARGET" and press
     `Enter` to put a cursor on each occurrence, then press `,` to keep
     only the primary (first) one:

  TARGET one and TARGET two and TARGET three.

7.6  CYCLING THE PRIMARY SELECTION

  (   cycle primary selection backward
  )   cycle primary selection forward

After multi-cursor operations, you can walk through which cursor is
"primary" (the one that anchors pastes, messages, etc.).

7.7  COPY SELECTION ON NEXT LINE

  C   duplicate the current selection on the NEXT line at the same column

This is useful for block editing — duplicate a cursor down through
several lines, then make the same edit on all of them at once.

  >> Press `C` twice to duplicate the cursor on the next two lines,
     then press `c` and type "REPLACED" `Esc`. All three lines change:

  original value = 1
  original value = 2
  original value = 3

7.8  TRIM AND SPLIT

  _   trim whitespace from the start and end of each selection
  S   split a selection that spans multiple lines into per-line pieces

  >> Select the three lines below with `Ctrl+x` three times, then press
     `S` to split into one cursor per line. With those three cursors
     active, press `_` to trim the trailing whitespace from each
     line at once:

  line one has trailing spaces   
  line two also  
  line three 

  ── Lesson 7 Summary ─────────────────────────────────────────────
  %           select all                s       split by pattern
  x / X       select line down / up     e       extend mode toggle
  ;           collapse to head          ,       keep primary only
  Ctrl+;      collapse to anchor        Ctrl+,  remove primary
  ( / )       cycle primary             C       copy on next line
  _           trim whitespace           S       split on newlines
  Ctrl+w / Ctrl+f<c> / Ctrl+t<c>   one-shot extend (kitty only)
  ─────────────────────────────────────────────────────────────────

  L E S S O N   8 — F I L E S   A N D   C O M M A N D S
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Typed commands begin with `:` followed by a name (and optionally an
argument), then Enter. Many have short aliases.

8.1  SAVING AND QUITTING

  :w              save (write) the current buffer to its file
  :w <path>       save to a different path (save-as)
  :q              close the current buffer; quit when no real file buffers remain
  :q!             close and discard unsaved changes
  :wq             save and quit
  :qa             quit the editor (refuses if any buffer is unsaved; use :qa! to force)

The tutor is opened as a sandboxed copy in a temporary directory
(something like `/tmp/hume-1234/tutor.txt`), so `:w` saves only to
that copy — the installed `runtime/tutor.txt` is never touched.
To get a fresh tutor, close this buffer with `:bd!` then reopen
with `:tutor`.

  >> Try `:w` now to confirm the path in the statusline is a tmp path,
     not your runtime directory.

8.2  OPENING FILES AND RELOADING

  :e <path>       open a file (creates a new buffer)
  :e              reload the current file from disk (prompts if dirty)
  :e!             reload and DISCARD unsaved changes

If you open a path that is already in a buffer, `:e` switches to that
buffer instead of opening a duplicate.

8.3  MANAGING BUFFERS

  :ls             list all open buffers
  :bnext  :bn     switch to the next buffer
  :bprev  :bp     switch to the previous buffer
  :b <name>       switch to a buffer by name, path prefix, or index
  :bd             close (delete) the current buffer
  :bd!            close even if unsaved

In any typed command that takes a path, `%` expands to the current
file's path and `#` expands to the alternate (previously focused)
file's path. For example: `:e #` reopens the alternate buffer.

8.4  OTHER USEFUL COMMANDS

  :version  :ver    show the editor version
  :messages :mes    review the message and error log
  :theme <name>     load a theme (dark / light / ember / gruvbox)
  :reload-config    reload the editor configuration file without restarting
  :pwd              print the working directory
  :cd <path>        change the working directory

  >> Try `:version` to confirm which build you are running.

  ── Lesson 8 Summary ─────────────────────────────────────────────
  :w / :w <path>   save / save-as         :e <path>   open file
  :q / :q!         close buffer / discard :ls         list buffers
  :qa / :qa!       quit all / force       :wq         save and quit
  :bn / :bp / :b   navigate buffers    :bd / :bd!  close buffer
  % = current file, # = alternate file in command args
  ─────────────────────────────────────────────────────────────────

This appendix sketches features not covered in the main lessons.

REGISTERS

Prefixing a yank, delete, or paste with `"<char>` stores into or
reads from a specific register. Valid register names:

  "cy   yank into the system clipboard register  c
  "cp   paste from the system clipboard

  "5y   yank into in-memory register  5    "5p   paste from register  5
  (registers 0–9 are symmetric named storage — "Ny/"Np round-trip)

  "kp   paste from the kill-ring head (most recent kill)
  "ky   push yank onto the kill ring (ring only, no clipboard)
  (older ring entries: cycle with `[` and `]` after a paste)

  "by   discard the yank (black hole — reads nothing back)

MACROS

  Q<r>   start recording into register <r>   (QQ  uses the  q  register)
  Q<r>   stop recording (same key ends the recording)
  q<r>   replay register <r>                 (qq  replays  q )
  <n>q<r>  replay <n> times

HUME uses uppercase to record and lowercase to replay.

UNDO TREE

Undo is linear: `u` steps back, `U` / `Ctrl+r` step forward.

SOFT WRAP

  :wrap   :toggle-soft-wrap   toggle line wrapping in the current pane
